# R-1j 事件多空对称性(Event Symmetry,F_symmetry)— 最终决策

**状态**: 锁定 2026-06-04(候选池准入)
**结局**: **DROP — 不进任何池**
**审计轨迹**: 本候选池快速轮无独立白板;三步快速判 + DROP 论证内嵌于本文件。

---

## 1. 候选本想测什么

F_symmetry 想量:**一类事件的结果方向是"注定的"(单向,如破产清算→几乎必跌)
还是"两可的"(双向,如季度财报→可涨可跌)**——一个 **sign-free**(只问"定不定"、
不带正负号)的结构属性,挂在结果方向环节(④)。

设想中的记忆故事:单向事件结果不靠记忆就能推出(照不出泄露),双向事件结果只能
靠记忆/信息(才照得出泄露)→ 想当"答对吃不吃记忆"的旋钮。

---

## 2. DROP 理由:切缝无非任意标准,被两边夹死

"单向 / 双向"这个值**不是良定义的**:它取决于把新闻切在哪儿——哪部分当"前提"
(条件)、哪部分当"结果"(待判)。同一条新闻,切粗(只给事件大类:「央行调整利率」
「公司发财报」)结果两可=双向;切细(连方向性内容也给:「央行降息」「财报利润下滑」)
结果注定=单向。**这条切缝没有一个非任意的标准**。

任何一种合理切法,都落到一个**已有因子**上,F_symmetry 自己没有独立中间地带:

- **切到最细 = 给模型看全文**(任务本就看全文)→ "结果定不定" = 文本本身把方向交代
  得多死 = **F_textdir(文本方向信息)**,卡 directional-label 红线。
- **切到最粗 = 只按事件大类** → "定不定"退成**事件分类法(F_topic)的一个降维属性**,
  且"切多粗"由 F_topic 的分类粒度说了算,F_symmetry 定不了 → **冗余于 F_topic**。

左边 F_textdir(红线)、右边 F_topic(冗余),中间无独立、定义清楚的地盘 → DROP。
按最小设计:一个"任何合理切法都落到已有因子上"的构念,不值得单占候选槽。

---

## 3. 机制余味的归宿(不在本因子承载)

- **"答对吃不吃记忆"(可预测性机制)**:由 **F_predict(结果可预测性,§1.3 红线族)**
  承载——F_predict 诚实承认自己在判方向、须独立于 P_predict 且依赖合法 sentiment
  标注闸门;F_symmetry 想绕过该判断而绕不过,故不另设。
- **"同方向散度的几类 topic 并一组"**:若 R-1u(F_topic)定下事件分类法后认为有解释力,
  作 **F_topic 内部的探索性重分组**处理,不在因子池单列。
