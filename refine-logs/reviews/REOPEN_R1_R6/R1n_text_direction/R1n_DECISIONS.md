# R-1n 文本方向信息(Text Direction,F_textdir)— 最终决策

**状态**: 锁定 2026-06-05(候选池准入)
**结局**: **纸面因子 F_textdir 不进池;反身化身 = exploratory 反身因子 F_predict(模型自判方向作 case 分箱),pilot 试。**

---

## 1. 候选本想测什么

一条新闻**光看文字本身**把某只股票往利好 / 利空说得有多明确(≠ 股票真实涨跌——那是 F_mktdir)。
设想:文字方向越明确,模型越能不读全文、靠先验猜对方向 → 泄露表现不同。

## 2. 纸面因子 F_textdir 不进池

要把"文字方向"当因子,须给每条 case 一个**独立于被测模型(P_predict)**的方向标签(真实股价=
事后禁、fleet 输出=循环禁)→ 只剩人工 / 外部裁判,成本高;且"文字方向"无非任意标尺:窄(只算
字面词)塌成情感词密度、冗余于密度族;宽(算常识推断)要调用金融先验本身、循环且真值松动。
而结果层"方向"已由 F_mktdir 便宜承载 → 不值这成本。

## 3. 反身化身:exploratory 因子 F_predict

问:模型是否更容易记住**它自己判成利好**的新闻(对比自判利空)。
- **它是因子**(回归横轴 / 分箱):拿模型自判方向(取自 P_predict)给 case 分箱,看记忆 / 泄露
  信号(纵轴)是否随箱不同。
- **反身、内生**:分箱标签随模型变、来自模型自身判断 → 不竞争 confirmatory 槽,走 **exploratory**。
- 代号 **F_predict**。pilot 试可行性 / 有无信号;完整操作化留下游。

- F_predict 的完整操作化(走下游)。
