# R-1s 结构方向先验(Structural Directional Prior,F_structdir)— 最终决策

**状态**: 锁定 2026-06-05(候选池准入)
**结局**: **DROP — 作 confirmatory 因子不进任何池**
**审计轨迹**: 本候选池快速轮无独立白板;三步快速判 + DROP 论证内嵌于本文件。

---

## 1. 候选本想测什么

某些**事件大类自带一个"课本方向"**:「央行降息」金融常识默认利好、「监管处罚」默认
利空。F_structdir 想量"这条新闻属不属于方向几乎写在脸上的事件类",挂在结果方向环节(④)。
设想的记忆故事:方向太"标准答案"的类,模型可不读正文、直接按先验填答案 → 抄近道(泄露)。

---

## 2. DROP 理由:被 F_topic / F_textdir 夹死,障碍在闸门上游

"结构方向先验"本质=**给每个事件类型贴一个方向标签**。事件类型这个旋钮(F_topic,R-1u)
已进池,于是落进和 R-1j 同构的两难、没有独立中间地带:

- **想干净(外部"事件类→方向"对照表查方向)** → 方向完全由事件类型决定 = F_structdir 是
  F_topic 的一个降维(粗刻度)属性,二者**冗余**,同一回归放不下两个。
- **想不冗余(细到分「财报超预期(+)」vs「财报不及预期(−)」)** → 这种细分光看事件大类
  查不出,须从正文读"这次是好是坏" = 退回**F_textdir(文本方向信息)**,卡 directional-label
  红线(方向打分须独立于 P_predict、禁真实股价 / fleet 输出)。

左边 F_textdir(红线)、右边 F_topic(冗余),中间无既独立又干净的地盘。

而该障碍**在 Type A 良性闸门上游**:F_structdir 作为因子变量在"被夹死"这一步就出局,
根本走不到"先验是良性背景能力还是泄露捷径"那道闸门 → 与 R-1r(F_entval)同判例:
障碍在闸门上游 → **DROP,非 pending**。按最小设计,"任何合理操作化都落到已有因子上"的
构念不值得单占候选槽。

---

## 3. 科学问题的归宿(不在本因子承载)

"模型靠不靠方向先验顶替读正文"这问题没丢:它住在**扰动抵抗**估计量层——对 F_topic
做 C_SR / C_FO 扰动看预测变不变(预测不变 = 用先验代替读文本 = 泄露)。不需单列 F_structdir 因子。
