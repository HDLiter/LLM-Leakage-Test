# R-1t 时期风格记忆(Regime Style Memory,F_regime)— 最终决策

**状态**: 锁定 2026-06-05(候选池准入)
**结局**: **DROP — 作 confirmatory 因子不进任何池**
**审计轨迹**: 本候选池快速轮无独立白板;三步快速判 + DROP 论证内嵌于本文件。

---

## 1. 候选本想测什么

某个**时间段整体带一种市场风格**("2020 后成长占优"、某段"高波动 / 避险"),挂在时期环节(⑥)。
设想的记忆故事:模型记住"这个时期是什么风格",看到该时期新闻就照风格答、不真读这条 → 抄时代背景的近道。

---

## 2. DROP 理由:风格无权威定义 + 冗余于 F_datebin,障碍在闸门上游

**两条独立的硬伤,任一即足以不进 confirmatory:**

1. **"市场风格"找不到权威定义** —— "成长 / 价值占优""避险"等风格标签无公认权威切法,
   且要给时期贴这种标签须**引入事后市场走势数据**回头判,违"标签须当时(ex-ante)可定";
   按项目惯例,无权威锚 → 无 metric 级 fallback,不预登记为 confirmatory。
2. **真有确定的风格时期,F_datebin 也能抓到** —— 时期记忆这根时间轴已被 F_datebin(R-1h)
   占住。风格按连续时段切 = F_datebin 细格子的粗粒度合并、与之**冗余**(同一时间轴换贴法,
   统计上分不开);按非连续市场状态切 = 仍是**整段时期一个常数**,不给案子层添独立变化。

附:整研究锚在训练截止时间(cutoff,pre/post);F_regime 是时间属性、横跨 cutoff,与
"post = 模型未训练过"主效应**纠缠不可拆**,更不可能当干净的 confirmatory 因子。

该障碍**在 Type A 良性闸门上游**:F_regime 作为因子变量在"被 F_datebin 夹死 / 无权威定义"
这一步即出局,走不到闸门 → 与 R-1r(F_entval)同判例:障碍在闸门上游 → **DROP,非 pending**。

## 3. 科学问题的归宿(不在本因子承载)

"时代风格记忆"没丢,它是**解释 F_datebin 结果的一个角度**,归 **F_datebin(R-1h)内部的
探索性重分组**(exploratory):pilot 后 F_datebin 若显出时期结构,再探"按某套**当时可定**的
风格分类法重新分组能否解释它",作 F_datebin 底下的探索分析,不单占 confirmatory 槽。
(同 R-1j 把 topic 重分组塞回 F_topic 底下处理。)
