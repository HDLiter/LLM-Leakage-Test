## 1. 候选测什么

标的的**方向性历史价格记录**——用**客观真实价格**(后复权)当合法案子标签,对应 R-1r 中无法测量的
"实体内部 valence 先验":案子内在、不依赖模型输出、不要方向标签。

## 2. 候选网格(6):三维 × 两锚

- **三维**:方向(净涨跌符号)/ 大小(|净涨跌|)/ 波动(路径离散),同一条历史价格读出。
- **两锚**(各自独立的因子列、**不交互**):
  - **published_at 锚** = 截至新闻日的历史价格(案子当时客观状态);
  - **cutoff 锚** = 截至模型 cutoff 的历史价格(模型训练能见到的那段;更贴泄露——测模型会不会
    顺这段历史方向当捷径)。
- 全 6 格作 confirmatory 候选(pre-pilot 新增,走 Stage 1 声明),pilot 选 / 降级;两锚版本之间 pilot 查共线。
- **带符号合一形式**(方向 × 大小 = 带符号 r)pilot 必测(量价方向族通用,见 memory
  `price_volume_signed_form`);适用方向格。

## 3. 共线盯防(pilot,VIF≥10 / |r|≥0.90 → R-1e 降级)

F_age(年轻票无长记录,按构造耦合)/ F_mktdir(事前方向 vs 事后结果方向)/ F_salience / F_mktcap
(蓝筹长期赢家三维都载荷)/ 族内两锚版本互查。

## 4. 操作化(定稿在 spec,要点)

raw 为主;36 月窗主、12 月稳健;留 1 月缝;方向纯符号(无中性带);波动 = 收盘到收盘已实现波动;
年限不够 = 缺失指示一种口径。**完整 + 源论文清单见 `R1w_operationalization_spec.md`。**
