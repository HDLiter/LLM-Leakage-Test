## 0. 一句话

这把尺子找记忆,靠**两个互补的信号**——各测一面,互相印证,但**不假设能合成一个量**:

- **信号一 = 抗扰动族(核心量)**:给文章做扰动变体,看模型预测变不变。不变 = 在用记住的旧结论 / 成见、而不是读眼前文字。它主要照**成见型记忆**(「茅台常涨」这种)。**它跨过 cutoff 之后是强是弱,我们不预测。**
- **信号二 = 熟悉度类(E_PCSG / E_CTS)**:读模型对这段文字眼不眼熟(见过的眼熟)。它照的是**对确切原文 / 结局的记忆**,而 **cutoff 是它的关键**——模型绝不可能见过 cutoff 之后的新闻,那批的熟悉度差会归零。**cutoff 这个干净的验证锚,落在信号二上。**

> **锚句(勿再写成确信)**:① 抗扰动族跨 cutoff 是强是弱**不预测**;② 那个「没见过就归零」的干净 cutoff 锚落在**熟悉度类(信号二)**、不在抗扰动族;③ 「抗扰动前后差能照出确切结局记忆」「两个信号能合成」都是**待验假说**,出结果前不写成事实。

到「虚假收益」是**动机侧的论证**,不是尺子本身能担保的(benchmark 不跑组合、不算收益)。

**实验还没跑——两个信号怎么混、抗扰动的前后差能不能照出确切结局记忆,都只是待验假说;凡需数据才能判的,一律推到结果分析阶段,现在不预设。**

## 1. 四层框架里的样子 + 量什么、凭什么信、主张多狠

**先看骨架 —— 四层框架**

整个实验按四层组织(这是项目核心骨架,后面所有操作化都挂在上面)。抗扰动族和截止点分属不同层:

| 层 | 是什么 | 在这里的角色 |
|---|---|---|
| **因子** | 案例自带的标签,**不改文本**,用来分组 / 交互分析 | **截止点**是其中一个**特殊**因子(= 验证锚);标的显著度、历史复现、时间线索强度等是**普通**因子 |
| **扰动** | 对文本的**受控改写**,一次只改一个维度 | 语义反转(利好↔利空)、假结局、实体匿名、无关插入……是**并列**的几种手法 |
| **算子** | 给「文本 + 模型」打分的函数 | 预测算子(让模型判涨 / 跌)、熟悉度算子(读模型对这段文字眼不眼熟) |
| **指标** | 把算子打分组合成、真正进统计的量(如比较「原文 vs 扰动变体」,或比较早 / 晚截止点的模型) | 这一整族就叫 **抗扰动族** |

**主量 = 抗扰动族(一族指标,不是单一某种扰动)**

用**预测算子**,比模型在「原文」和「某个扰动变体」上的预测变没变。越不变 = 越没在读眼前文字、越像在用记住的旧结论 = 记忆嫌疑越大(底层是两次预测的配对比较,差越小、抵抗越强)。

它是一个**族**:配语义反转(利好改利空)是一个成员,配假结局是另一个成员……**用哪种扰动当主力,是后面「扰动会议」的事,P0 不锁** —— 所以本文用「扰动」泛指,不钦定语义反转。

**抗扰动族 和 截止点 是两层、两件事**

- 抗扰动族是**「量什么」**:它是一族**指标**(第四层),逐「案例 × 模型」算出来。
- 截止点是**「凭什么信」**:它是个**因子**(第一层),是特殊的验证锚——但要分清,**它那个干净的锚落在信号二(熟悉度)上,不是直接验证抗扰动族**。

**凭什么信它量的是记忆(两个信号各有依据,互相佐证、但不预言会合)**

- **信号二(熟悉度类 / E_PCSG)** 靠 **cutoff 干净锚**:模型没见过 cutoff 之后的新闻,那批的熟悉度差就该归零——这条能被「上帝视角」证伪。
- **信号一(抗扰动族)** 靠**扰动设计本身**:模型若抵抗反事实改写(利好改利空还不变),说明它在用缓存结论、不是读眼前文字。**它跨 cutoff 的行为不预设。**

两条各测一面(成见 / 确切结局),**不假设能合成一个量**。这种两条互相印证的思路就是「会聚效度」,但**我们不把它当预设判据**——实验出结果后,可以看看它俩之间有没有相关线索(比如同一批新闻上是否一起强弱),那是事后观察。

(注:截止点享特殊地位是合法的——它给出「绝不可能见过」这个近上帝视角判据;标的显著度、历史复现这些是普通因子,**不预派当效度判据**。)

> **注:cutoff 相关的信号不止熟悉度类。** 还有候选估计量如**「预测稳定性」**(同输入重复采样的稳定度——见过 → 更稳,没见过 → 更散;cutoff 前后变的可能是**稳定性**而非点预测)——登记在四池 §4、留估计量 / 扰动会议;**P0 不锁这些**,只点明熟悉度类不是唯一的 cutoff 信号。

**主张说到多狠**

论文主张 = **这把尺子量的是广义记忆**。「广义记忆」含两面:① 模型背下了这条具体新闻的结局;② 模型养成了一般方向成见(「破产必跌」「茅台常涨」这种不依赖某条特定新闻的偏见)。两面都算记忆——但**由两个信号分别去照**(成见型主要靠抗扰动族、确切结局主要靠熟悉度类),**不假设能合成一个量**;偏见本质上也是模型从历史语料积累的、可能歪曲当前判断的先验。

**「能不能把『背了结局』从『一般成见』里单独拆出来量」= 留结果分析阶段判。** 现在不预注册为主张、不当承重墙;分析时凭哪些因子有信息说话来读,而不是现在就指定某个因子(比如标的显著度)当分离工具。**实验跑之前,所有因子一视同仁。**

## 2. 到「虚假收益」那座桥

**性质 = 纯论证**

这个 benchmark 不跑投资组合、不算收益率、不做风险调整。动机里提到的「虚假 alpha / 虚假收益」,和我们实际测量的「记忆痕迹」之间,靠一段**论证**连接,不是靠尺子直接给出。

**论文可以说「我们测的是会导致虚假收益的那种记忆」;不能说「我们测了虚假收益本身」。** 前者是刻画,后者是应用——措辞红线划在这。

**说到「记忆」时,承重的措辞永远是「记忆 / 抗扰动族」**,不用「记忆抬升」这个词当同义替换——「抬升」这个说法血统上来自「截止点前后准确率差」那套框架,容易把已经溶解的旧争论重新召回来。

**虚假收益可能的三条通道(读结果时的 checklist,不是现在就能断言的因果链)**

1. **截止点前后的模型表现差异**(预测本身或预测的稳定性)——放到真实金融管线里,这意味着回测反映不出模型真实性能,是量化研究的大忌。注:测量侧读的是抗扰动族(信号一)和熟悉度类(信号二)这两个量本身,**不是**把「前后准确率差」当台面主指标。
2. **模型对扰动的抵抗**(以语义反转为例:把利好改成利空)——模型预测不跟着变 = 偏见/记忆入脑,读不进眼前文本。
3. **模型对某些因子的过度反应**(比如特定年份的新闻、经常被报道的标的)——预测模式剧变 = 推理被非金融模式干扰。

这三条是实验结果出来后**回头检视**用的思路,不是现阶段能下的因果结论。

## 3. 真实涨跌对照

- **定位 = pilot 阶段顺手看一眼的旁证,不单独设为常设指标。**
- 理由:一篇短新闻面对真实市场的无数变量,模型预测「涨」、股票也确实涨了,不能说明模型做了充分推理——你选中的可能只是一条无足轻重的侧面利好,根本不是推动股价的真正原因。所以拿来当 sanity check 可以,寄望它给出强结论不现实。
- 真实收益可以作为**案例标签**(比如「涨得猛的新闻是不是更容易被记住」这种分析维度),但不进正式指标。
- **信息新颖度**(novelty)维持「非主因子」,最终归宿在后续 P5 会议。

## 4. 开题报告 §4.6

- **维持现措辞不动**。§4.6 写的「正式指标不与真实股价对照、不碰已实现收益」,和我们的原则一致。

## 5. 交给下游会议

以下是 P0 传递给各后续会议的接口。每条只说 P0 定了什么、下游需要接什么。

**P2 — 判据的精确措辞**

**分信号写「没记忆时该读到几」,别合并成一句:**
- **信号二(熟悉度类 / E_PCSG)**:截止点后该读 ≈ 0(模型没见过 → 熟悉度差归零),这是干净锚。注意截止点是渐变非阶跃,「≈ 0」是软下界、措辞含缓冲带;时间线索强度(F_temporal)是普通因子、和 cutoff 验证锚分属两事,别混。
- **信号一(抗扰动族)**:截止点后是强是弱**不预设**(成见型记忆可能仍在)——**不给它安「post-cutoff 归零」判据**;「前后差能否照出确切结局记忆」留作假说、结果分析期看。
- 原始预测准确率:截止点后 ≠ 0(基准率 / 乐观 / 地域偏见都在)。

**P3 — 任务信息集**

本文未给「预测真实涨跌的准确率」开正式(confirmatory)角色,因此信息新颖度复活的前置条件不被 P0 触发。

**P4 / R-6 — 预测目标与真实收益口径**

§2 那座桥的通道 1 需要 P4 锁定预测标签和时间窗;真实收益(pilot 旁证 + 作案例标签的因子)的具体口径在此落地;§4.6 在此重写。

**P6 — 虚假收益主张的边界措辞**

写 proposal 方法/讨论章时,用 §2 的框:桥 = 纯论证,承重词永远是「记忆/抗扰动族」,三通道 checklist 当读结果时的参照。

**P7 — 每个因子调的是「记忆」还是「基础能力」**

验证各个正式因子影响的到底是记忆增量还是原始准确率;标的显著度与历史复现这类曝光类因子之间的共线问题在此查。

**扰动会议**

- **扰动有效性验证**(确认所用的扰动真被模型察觉)列为抗扰动族成立的硬前置,但具体设计(含选哪种扰动)归扰动会议。
- 实体匿名手法优先考虑——它直接打掉实体身份(一般方向成见的最大载体),对分离「背了结局」vs「一般成见」有补充价值。
- 无关插入安慰剂是当前可得的负对照。

**因子扩展会议**

- 带方向的先验因子(实体好恶倾向、结构性方向先验)仍在「Type A 良性闸门」后。
- 行情因子族(真实涨跌方向/幅度/市值当案例标签)的正式身份在此拍。
- 方向标注来源见 `archive/r4_r5a_lineage/refine-logs/reviews/REOPEN_R1_R6/R4_methodology_audit/directional_label_probe.md`。

**pilot**

结果分析期需关注三件事(全部为不确定、非预注册主张):
1. 抗扰动族的截止点前后差能不能估出——这是「它能否照出确切结局记忆」那个**假说**要看的,不是预设的判据;
2. 两个信号(抗扰动族 + 熟悉度类)之间有没有相关线索——在同一批新闻上是否一起强弱、是否被同一批高频实体等共同混杂一起带高(事后观察,不预设);
3. 「背了结局」vs「一般方向成见」在哪些因子上能分开。
