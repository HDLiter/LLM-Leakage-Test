## 0. 总纲(整个设计的轴)

> **测量的本体 = 同一个算子,在「因子变化」(如 cutoff)或「施加扰动」(如 C_SR)
> 前后,输出的变化。**

- **因子(F_)**:案例**自带**的标签,**不改文本**。作用方式 = 分层 / 交互(看信号随因子怎么变)。
- **扰动(C_)**:**主动改**文本,只改一个维度。作用方式 = 配对相减(原 − 变体)。
- **算子(P_)**:`(文本, 模型) → 一组衍生变量`。无状态,不知道扰动 / 因子 / 设计。**只管把痕迹记全**;一次调用产出**多个衍生变量**(P_predict → 离散方向 / logprob 置信度 / 选项分布),且任何算子都有一个**多次运算离散度**的元维度。
- **指标(E_)**:挑「哪个算子衍生变量」+「比哪些变体 / 模型对」+「什么比较」得到能进统计模型的量。**每个必须写明:我测的是哪方面。**

> **⚠️ 没有第五层「读法层」(本轮自我纠正)**。PC / CI / IDS / 采样离散度**不是**新层 —— 它们 = 「算子衍生变量」×「指标比较」的组合(§3.1 + §4.3)。把它们立成一层会重犯四层框架当初要溶解的范畴错误(把"算什么分数"和"分析什么量"混为一谈)。

**命名约定**(本文档内的工作标签,**非 canonical lock**,便于交叉引用):
`F_` 因子 / `C_` 扰动 / `P_` 算子 / `E_` 指标。

**三条被本轮改写的全局判据**(贯穿所有指标,见 §5):
1. **无记忆基线**(各测量指标的基线不同) —— 不"一刀切读零"。
2. **会聚效度** —— 两个不同算子都过锚才算强。
3. **衍生变量 tier 可得性** —— CI/IDS 依赖的算子衍生变量只白盒 logprob 有,黑盒确认性只用离散方向(PC)。

## L3 — 算子(Operator)

> 大致计算已知,**具体落地待定义**。核心修正:**"读哪个角度"不是算子的事,是指标的事**;
> 算子只管把痕迹记到最全。

| 码 | 算子 | 大致计算 | 接入 | 覆盖 | 落地待定义 |
|---|---|---|---|---|---|
| **P_logprob** | 尾部意外度 | token 对数概率,取 bottom-K% 校准均值(Min-K++/CTS) | 白盒(需 logprob) | 12 白盒 | thinking 必须 OFF;K% 取值;频率校准 |
| **P_predict** | 标准化预测 | 冻结任务 prompt 喂文章,记方向预测 | 黑盒即可 | 16 全 | **🆕 必须"记全"(见下)** |
| **P_extract** | 掩码补全 | 遮正文后半数字/实体/结局,让模型补,算精确/模糊匹配 | 黑盒即可 | 16 全 | reserve;命中稀疏 |
| **P_schema** | 模板补全(候选) | 给 CLS 前缀让模型续写,比对真实续写 | 黑盒即可 | 16 全 | 候选;须验证与 P_logprob 部分独立 |

### 3.1 🆕 算子衍生变量 + 离散度元维度(本轮架构修正)

**一次算子调用 → 一组衍生变量**,不预设下游怎么读。以 P_predict 为例,每次 `(模型, 案例, 扰动)` 须记全:
1. **离散方向** ∈ {涨 / 跌 / 平} —— 全 fleet(衍生变量①)。
2. **白盒**:决策 token 上对三候选词 renormalize 的**概率向量** + **原始 per-choice-token logprob
   (不只 argmax)**,**T=1**,记**决策 token 位置** —— 仅白盒(衍生变量②=置信度 / ③=分布)。
3. **黑盒**:k 次重复采样 或 自报分数 —— pilot/exploratory。

**离散度是所有算子共有的元维度**(不是 P_predict 专属):任一算子重复运算 k 次 → 结果离散度 / 方差。
**注意**:只有**带采样的算子**(P_predict / P_extract / P_schema,T>0)离散度才非退化;P_logprob 单次
前向是确定的,其"多次离散度"退化为 0(除非跨 paraphrase / 跨 token 位置另行定义),故离散度主要挂在
采样型算子上。

### 4.3 🆕 抗扰动指标的衍生读法 = 「算子衍生变量」×「比较」(**非独立层**)

> 本轮架构修正:下面四行**不是**第五层,而是同一个抗扰动比较(原 − 扰动)作用在**不同的算子衍生
> 变量**上,即 `E = 比较(算子衍生变量, 原 vs 扰动)`。立成"读法层"是范畴错误,已撤。

| 读法 = 变量 × 比较 | **测哪方面** | 算子衍生变量 | 覆盖 | 状态 |
|---|---|---|---|---|
| **PC** = 离散方向 + 差 | 离散答案翻不翻——**答案稳定性** | 离散方向① | 16 全 | ✅ **锁,主读数** |
| **CI** = 置信度 + 差 | 笃定程度变多少(**只读相对差**,绝对校准被记忆污染) | logprob 置信度② | 仅白盒(**不用自报**) | 候选,pilot |
| **IDS** = 分布 + KL | 扰动前后整个分布挪多少 | 选项分布③ | 仅白盒 | 候选,pilot(**KL 量自身稳定性也要验**) |
| **采样离散度** = 方差(元维度) | 同输入下模型自己多笃定(见过→方差小,没见过→方差大)。黑盒唯一分布型出路 | 离散度元维度 | 16 全(×k 成本) | 候选,pilot |

> 文献坐实(本轮):**自报置信度不可靠**(Qwen 上崩、自相矛盾);可靠分布/置信度只能读白盒
> logprob;**记忆-过度自信伪迹**(记忆 case 置信度饱和→CI 差值被压扁、IDS 被极端概率主导),
> pilot 须用 pre/post 分布尖锐度专门拆。文献无人算过 pre/post 扰动 KL → **IDS 是首创,pilot 验
> 这个量本身稳不稳**。

> **🆕 候选估计量「预测稳定性」(P_predict 重复稳定度,2026-06-01 owner)**:上面的「采样离散度」现在挂在抗扰动比较的读法里,但它本质是 P_predict 在**同一输入**上重复采样(T>0,k 次)的离散度——**不靠扰动也成立**,可单独立为估计量。作记忆信号:见过 / 高显著 → 预测更稳(方差小),没见过 → 更散。**cutoff 角度(owner 洞见)**:cutoff 前后变的可能不是点预测、而是**稳定性**——故「预测稳定性 × cutoff」是又一条 **cutoff 相关候选估计量**(与熟悉度类 E_PCSG/E_CTS 并列、互补;也是黑盒的「置信度」路子,CI 只白盒)。**pilot 须验**:① 量非退化(需 T>0;P_logprob 单次前向确定、不适用);② 防**「稳定地错」混杂**(模型可能自信地错,稳 ≠ 记忆);③ 与 CI / 采样离散度的关系。状态:候选,pilot。

## 5. 三个被改写的全局判据(贯穿所有指标)

1. **无记忆基线**(各测量指标的基线不同,取代"cutoff 后一刀切读零"):
   - E_PCSG cutoff 后读 **≈ 0**(模型没见过 cutoff 后的新闻 → 熟悉度差归零);
   - 抗扰动差值:post-cutoff 行为**不预测**(成见型记忆可能仍在;「pre−post 抵抗能照出确切结局记忆」= 假说,见 `P0_DECISIONS.md` §0/§1);
   - 模型预测(P_predict 在原文上的输出)读 **≠ 0**(基准率+乐观+地域偏见都在);
   - 持续偏见(实体/因子/共现…)读 **≠ 0 且正面去量**。
   - 外部佐证:逐字记忆 vs 学到偏见是两个量该并存(2603.03203 / 2604.13997);抗扰动=记忆有
     机制根据(2603.21658);cutoff 是渐变非阶跃,故只能为"记忆差值读 0"辩护、**不能为
     模型预测读 0**(TempoMed-Bench 2605.13045)。
2. **会聚效度**(P0 已收紧,canonical `P0_DECISIONS.md` §0/§1):行为通道(P_predict 抗扰动)× 惊讶度通道(P_logprob)两个不同算子各测一面(抗扰动族=成见型记忆、熟悉度类=确切结局记忆),互相佐证但**不假设能合成**,也**不当预设判据**。两通道是否一致指向记忆、是否被同一共同混杂(如高频实体)带动(= 通道独立性:来源不同源、非统计独立)= 实验出结果后的**事后观察**。**干净 cutoff 锚只在熟悉度通道,抗扰动族不预设 cutoff 行为**(靠扰动设计本身立)。**不需要 E_CMMD 当第三条腿**(故砍它不可惜)。
3. **衍生变量 tier 可得性**(原"读法分层"):CI/IDS 依赖的衍生变量②③只有白盒 logprob 能给
   (否则白盒 vs 黑盒缠进泄露信号 = 构念效度灾难);黑盒确认性设计**只用离散方向①(PC)** +
   采样离散度元维度当探索。
